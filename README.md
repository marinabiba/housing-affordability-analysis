# Housing Affordability Analysis: Rent vs. Buy

## Project Overview

This project analyzes housing affordability and compares renting versus buying a home using historical housing and rental data. The goal is to examine how housing costs have changed over time and determine how those changes affect the financial decision to rent or purchase a home.

## Business Question

How have housing and rental costs changed over time, and under what conditions may purchasing a home be more financially advantageous than continuing to rent?

## Tools Used

- Microsoft Power BI
- Power Query
- Microsoft Excel
- Data Cleaning
- Data Visualization
- Exploratory Data Analysis

## Data Analysis Process

1. Collected historical housing and rental market data.
2. Reviewed the dataset for missing values, formatting issues, and inconsistencies.
3. Cleaned and transformed the data for analysis.
4. Compared housing and rental costs across different time periods.
5. Created calculated measures to evaluate changes in affordability.
6. Developed interactive Power BI visualizations to identify trends and differences.
7. Interpreted the results to determine the factors influencing the rent-versus-buy decision.

## Dashboard

A Power BI dashboard will be included to visualize housing costs, rental trends, and affordability changes.
